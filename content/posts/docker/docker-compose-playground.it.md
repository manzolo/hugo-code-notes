# Docker Playground Manager 🐳

Ecco **Docker Playground Manager**, uno strumento potente per gestire gli ambienti di sviluppo Docker! Avvia container per fare test, imparare o sperimentare con più di 100 immagini già configurate (Linux, Python, PostgreSQL, ecc.) da un'interfaccia interattiva a terminale.

## Cosa c'è di nuovo? ✨
- 📚 Guide MOTD per MySQL, PostgreSQL e altro ancora.
- 🎯 Scelta dei container per categoria.
- 📺 Nuova dashboard e statistiche migliorate.

## Per cominciare 🚀
```bash
git clone https://github.com/manzolo/docker-compose-playground.git
cd docker-compose-playground
chmod +x playground.sh
./playground.sh
```

Scopri tutte le funzioni su [GitHub](https://github.com/manzolo/docker-compose-playground). Provalo, dimmi cosa ne pensi, o contribuisci per renderlo ancora migliore!
